على البوابة الموظف بيعمل scan للـ QR:
- `POST /Sessions/:Id/CheckIn` بـ `{ Code }`: لو التذكرة سليمة وبتاعة الحفلة دي يدخل، والتذكرة تبقى `CheckedIn`. الرد `{ TicketId, Status }`.
- تذكرة دخلت قبل كده: 409. تذكرة حفلة تانية (مثلاً بتاعة الخميس واتعملها scan يوم الجمعة): 409. كود مش موجود: 404.
- البوابة بتفتح قبل الحفلة بـ 3 ساعات، أي scan قبل كده: 409.
