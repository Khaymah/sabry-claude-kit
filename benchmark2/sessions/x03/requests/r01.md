هنبدأ نبيع تذاكر حفلات وإيفنتات، وكل إيفنت تبع منظّم (Organizer) من المنظمين اللي بنشتغل معاهم:
- `POST /Organizers` بـ `{ Name }` يعمل منظم، والرد فيه `Id` و `Name`. و `GET /Organizers` يجيب منظمين الشركة.
- `POST /Events` بـ `{ OrganizerId, Name, Sessions: [{ StartsAt }], Categories: [{ Name, Price, Capacity }] }`. الإيفنت ممكن يبقى ليه كذا حفلة (Session) كل واحدة ليها `StartsAt`، وفئات كراسي (VIP، عادي...) كل فئة ليها سعر و `Capacity`. الـ Capacity دي لكل حفلة لوحدها: VIP بـ 50 كرسي يعني 50 في كل حفلة. `Price` بالجنيه string زي `"150.00"` زي باقي فلوس السيستم.
- `GET /Events/:Id` يرجّع `{ Id, OrganizerId, Name, Status, Sessions: [{ Id, StartsAt }], Categories: [{ Id, Name, Price, Capacity }] }`، والإيفنت الجديد `Status` بتاعه `OnSale`.
- `GET /Events/:Id/Availability` يرجّع `{ Items: [{ SessionId, CategoryId, Capacity, Available }] }` لكل حفلة × فئة.

نفّذ. ماتسألنيش، افترض الافتراضات المنطقية واذكرها في الآخر.
