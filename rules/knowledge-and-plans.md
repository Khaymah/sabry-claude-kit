# Knowledge and plans

- **Kit knowledge:** `Patterns/` before proposing a feature · `Anti-patterns/` when reviewing or debugging · `Decisions/` for "why did we pick X?" · `CommunicationProfiles.md` when writing for someone other than the owner.
- **Plans in files:** a plan, analysis or task set is written to a `.md` file, not only shown in chat; each task is self-contained.
- **`Plan/Progress/YYYY-MM-DD.md`** is the daily log and the handoff between sessions: append a section per work session, ending with the `**الجاي:**` and `**مفتوح:**` lines. Format: `Reference/progress-log.md`.
- **Long tasks** (more than one session, or three or more phases) get a checkbox plan in `.agents/plans/<slug>/plan.md` before work starts. The session brief names the active plan and its next item: continue from there, tick boxes as tasks are done **and verified**. How: `Reference/long-task-plans.md`.
- **Lessons:** when the owner corrects you ("غلط" · "قلتلك" · "wrong"), fix it, then record one lesson with the command the `[lessons]` reminder gives. A `[lessons]` block in context is a standing correction: apply it without being asked again. No secrets in a lesson.
