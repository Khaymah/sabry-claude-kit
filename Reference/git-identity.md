# Git identity

Cloud sessions ship a global git identity of `Claude <noreply@anthropic.com>`; a clean message is not enough if the commit is still recorded under Claude's name.

- `git-identity` applies the owner's `git_name` / `git_email` from the profile at session start.
- Missing from the profile → ask the owner once (`AskUserQuestion`), set `git config user.name/user.email` in the repo, and save them with `kit_profile.py set '{"git_name":"…","git_email":"…"}'`.
- Never commit with `--author` or `GIT_AUTHOR_*` set to an AI. Rewriting an already-pushed commit to fix its author needs a force push: ask first.

Where attribution is banned: commit messages, tags, merge/squash messages, PR and issue titles and bodies, PR comments, review comments, release notes — through `git`, `gh`, `gh api` or any GitHub/GitLab MCP tool. That includes a `---` separator followed by `_Generated by [Claude Code](…)_`: drop the trailing block entirely.
