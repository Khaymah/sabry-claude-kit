# Reference

Detail that the injected rules point to. Read a file when the rule that names it applies; nothing here is loaded at session start.

| File | Read when |
|---|---|
| `progress-log.md` | Writing the day's section in `Plan/Progress/` |
| `definition-of-done.md` | Closing a feature, bugfix, refactor or migration |
| `long-task-plans.md` | Starting or continuing a task that spans sessions |
| `subagent-briefing.md` | Briefing a subagent |
| `stack-list.md` | Recommending a technology outside the default stack |
| `git-identity.md` | The git author is missing or wrong |
